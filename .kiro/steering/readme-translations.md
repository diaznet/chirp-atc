# README Translation Rule

When modifying `README.md`, always propagate the same changes to the translated README files:

- `README.fr.md` (French)
- `README.de.md` (German)

Translate any new or updated content into the respective language. Keep area names, CLI output blocks, code snippets, and file paths unchanged — only translate prose, headings, and descriptions.
